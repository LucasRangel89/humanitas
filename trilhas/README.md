# trilhas/

Uma trilha é um caminho ordenado de estudo dentro de um tema — o "Modo Trilha" do blueprint Humanitas Explore: cada nó é uma nota de conceito, do fundamental ao complexo, como uma árvore de habilidades.

- Use o modelo `templates/template-trilha.md` para criar cada trilha. Nome dos arquivos: `tema-nivel-1.md`.
- Todo nó da trilha aponta para uma nota existente em `conceitos/` — se a nota ainda não existe, crie-a antes de marcar o nó.
- A trilha convive com o **Modo Exploração Livre** (Guia 02): sair da trilha para perseguir uma curiosidade não é falha, é o jeito das ciências humanas.
- Marque um nó como concluído só cumprindo o critério: explicar em voz alta, quiz do Tutor e entrada no diário de bordo.

A trilha semente `psicologia-nivel-1.md` já vem preenchida com as 13 notas semente do painel — use-a como exemplo vivo.
