# trechos/

Citações literais guardadas com um propósito: cada trecho vem acompanhado de um comentário pessoal explicando por que foi selecionado.

- Use o modelo `templates/template-trecho.md` para cada recorte.
- Nome dos arquivos: `autor-tema-curto.md`, por exemplo `carr-fatos-e-interpretacoes.md`.
- Trecho sem comentário é recorte; trecho com comentário é estudo. O comentário é a parte que não pode faltar.
