# indices/

O mapa geral do acervo processado.

- `indice.json` lista os livros convertidos, com título, arquivo e contagem de palavras. Ele é gerado automaticamente pelo notebook `notebooks/converter-pdfs.ipynb` (última célula) e também pode ser editado à mão.
- Sempre que adicionar livros ou notas novas, atualize o índice — é ele que permite saber, de relance, o que já foi processado e o que ainda falta.
- A tabela "Painel de temas" do `README.md` é a versão legível deste índice.
